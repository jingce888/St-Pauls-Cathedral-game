# St Paul's Cathedral · 圣保罗大教堂 3D 观景漫游

A first-person sightseeing walk around, into and up St Paul's Cathedral, London — built at true
scale in the browser with three.js.

一款以伦敦圣保罗大教堂为核心的第一人称 3D 观景游戏：按真实比例复刻教堂与周边街区，可在广场环绕观赏、穿过各个大门进入教堂、沿 528 级台阶登上金廊俯瞰伦敦。

## 运行 · Running

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/（相对路径，可部署到任意子目录）
npm run preview
```

地址参数：`?q=low|medium|high|ultra` 强制画质档位（默认按设备自动选择）。

## 操作 · Controls

| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 行走（Shift 快走） |
| 鼠标 | 环顾（点击画面锁定鼠标） |
| 右键按住 / 滚轮 | 望远镜缩放 |
| E | 查看眼前景物的介绍卡片（中英双语：管风琴、祭坛、马赛克、油画、山花浮雕…） |
| L | 显示/隐藏地标标签（在石廊、金廊上） |
| T | 切换时间（黎明、正午、黄昏、夜晚…） |
| P | 拍照模式（隐藏界面） |
| Esc / Tab | 菜单：传送、光照、画质、视野 |

触屏设备：左侧虚拟摇杆行走，右侧拖动环顾，双指缩放。

## 内容 · What is modelled

**外部**：西立面双层柱廊与双塔（南塔钟面）、两翼半圆形门廊、穹顶鼓座与外穹顶、采光亭与金球十字；
三座山花浮雕——西山花《圣保罗归信》、北山花王室纹章与天使、南山花浴火凤凰与 RESURGAM；
西大门上方《圣保罗在庇哩亚传道》浮雕、两翼大门上方的涡卷徽饰、每扇窗拱心石上的带翼小天使头像、
成对壁柱之间的花果垂饰、檐口托架、栏杆与雕像。周边街区来自 OpenStreetMap。

**内部**：中殿、侧廊、唱诗席与后殿，穹顶下八根墩柱与拱券；
大管风琴（南北两半，镀金音管、塔楼、雕刻）、西端国事号角管、唱诗席座椅与主教宝座、
高坛与螺旋柱镀金华盖、讲道台、鹰形读经台、洗礼池、中殿吊灯；
拱心石天使、拱肩“荣耀女神”浮雕、檐壁花环、侧廊大理石纪念碑；
金色马赛克壁画——穹顶拱券上方的四福音书作者与四先知、后殿《荣耀基督》、唱诗席穹顶《创世》，
侧廊油画《世界之光》（霍尔曼·亨特）与《圣母领报》，桑希尔穹顶画。

**登顶路线**：地面 → 257 级到回音廊 → 376 级到石廊 → 528 级到金廊，楼梯、平台、门洞完整衔接，
坠落保护会把人放回最近的安全位置；界面实时显示台阶数与高度。

## 工具 · Tools

- `node tools/route.mjs` — 无头浏览器自动行走：从卢德盖特山经西大门登顶再下来，并逐一穿过每扇大门、走唱诗席到祭坛、绕三层观景廊一圈；卡住或坠落即失败。
- `node tools/shoot.mjs --tag=x --poses=west,organ,apse` — 按预设机位截图到 `shots/`。
- `node tools/relief.mjs conversion arms phoenix` — 单独预览浮雕（`tools/relief.html`）。

## 技术要点

- three.js r186 + Vite + TypeScript；程序化几何（`src/geo/Builder.ts`），每个顶点携带“语义涂装”（接缝、雨水侵蚀、凹陷遮蔽），由材质着色器转换为波特兰石、铅皮、黄金等外观。
- 浮雕为高度场雕刻（`src/geo/relief.ts`）：人物、马、翅膀、花叶、文字等图元按层叠加，烘焙凹陷阴影；小件以实例化方式大量复用。
- 马赛克与油画在加载时用 Canvas 程序化绘制（`src/gfx/art.ts`），马赛克材质逐块采样并让金色镶嵌片呈金属反光。
- 静态双级联太阳阴影、大气散射天空与空气透视、室内外曝光自适应、BVH 碰撞与悬浮胶囊角色控制。
